# Software 2027
Software for KIPP in the 2026/27 terms.

### Conventions and High Level Goals

- All changes to `main` must be done via Pull Requests on Github
- Task tracking will be done with [Github Issues](https://github.com/UofA-SPEAR/software-2027/issues)
- Reuse code from [last year's repo](https://github.com/UofA-SPEAR/software_2026) when possible/it makes sense, but in a more maintainable way. 
- Document things either in-code or in the `docs/` directory
- Build out an interaction library that mission code can use to simplify automation
